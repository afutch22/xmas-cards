Drawing so it can move

Whichever you pick, these rules keep your drawings easy to animate.

Canvas and layers

  1. Canvas 2160 × 2700 px (double the card frame, so it stays sharp).
  2. Anything that moves gets its own layer. Bow loops, tails, the cat's tail, each ornament, each flame.
  3. Draw a little past where pieces overlap, so no gap shows when something swings.
  4. Keep the background (paper, wall, static tree) on one flat layer.

Exporting

  1. Moving pieces as PNG with a transparent background.
  2. For "ink draws itself", line art as SVG strokes. Procreate can't export SVG, so trace in Illustrator, Affinity, or Figma's pencil tool.
  3. The background as one JPG.
  4. Name files by what they are, like bow-loop-left.png.
